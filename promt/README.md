## How to use this folder
Read `00_MASTER_BRIEF.md` and `01_PRODUCT_RECORD.md` first. Execute versions in numeric order. Each version prompt is a self-contained, detailed build instruction for its scope; tick its checklist only after inspecting the actual result. Do not skip ahead when a prior version's exit criteria fail.

## Versions
1. `V1_PRODUCT_AND_MYSTERY.md` — resolve product definition, case truth, suspects, evidence, timeline, logic rules.
2. `V2_UI_UX_AND_VISUALS.md` — screen-by-screen interface, navigation, responsive behavior, colors, controls and interaction states.
3. `V3_ARCHITECTURE_AND_GAME_LOGIC.md` — state model, engines, deterministic rules, persistence and hidden/visible data boundaries.
4. `V4_IMPLEMENTATION_AND_INTEGRATION.md` — implement the playable game incrementally and wire every screen to real behavior.
5. `V5_QA_AND_RELEASE.md` — verify build, complete case flow, checklist, fix defects, document run instructions.
