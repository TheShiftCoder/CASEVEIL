# Visual Design Specs

- **Palette**:
    - Background: `#0B0E13`
    - Panels: `#131923`
    - Secondary: `#1A2230`
    - Borders: `#293344`
    - Text (Primary): `#E8EDF5`
    - Text (Muted): `#8995A7`
    - Accent: `#D6A35D`
    - Secondary Accent: `#7289A6`

- **Typography**: Inter (or sans-serif system), clean, weighted for hierarchy.
- **UI Feel**: Cinematic dark mode, subtle borders (1px solid), minimalist, high contrast for actionable elements.
- **Feedback**: Subtle transition states, glowing highlights on active clues, clean log typography.
